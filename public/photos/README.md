# Фотографии

Файл с именем слота (jpg, png или webp) появляется в приложении вместо плейсхолдера.

| Файл | Где показывается |
|---|---|
| `hero-burger.jpg` | главная, слева в hero (круг) — двойной чизбургер |
| `hero-fries.jpg` | главная, справа в hero (круг) — фри в картонке GRAFF |
| `cat-burgers.jpg`, `cat-fastfood.jpg`, `cat-new.jpg`, `cat-tea.jpg`, `cat-jam.jpg`, `cat-drinks.jpg` | меню, фото раздела |
| `dish-<id>.jpg` | карточка блюда; id — как в `src/data/menu.ts`, например `dish-burgers-0-0.jpg` (Бургер классический, мясной) |
| `new-<id>.jpg` | карусель «Новинки ★» на главной, например `new-new-0-0.jpg` (Фахитас с мясом) |
| `about-map.jpg` | «О нас» — карта |
| `about-hall.jpg`, `about-terrace.jpg` | «О нас» — фото зала и террасы |

Рекомендуемый формат: реалистичное фото на кремовом фоне с мягкой тенью (как в печатном меню),
760 px по длинной стороне (карточка во весь экран телефона с запасом на плотный экран).

## Замена фотографий прямо в приложении

Любой снимок из таблицы можно поменять без пересборки: **Профиль → Режим персонала →
Фотографии кафе** (два круга на главной, зал, терраса, карта) и **Фотографии блюд**
(обложка раздела и каждое блюдо, раздел выбирается вкладкой). Кадр уменьшается до 900 px
и пережимается в JPEG — снимок с телефона можно ставить как есть.

Круглые фото на главной там же целиком убираются, если своих фотографий пока нет —
заголовок «Меню» тогда встаёт по центру.

Выбранный так снимок хранится в этом браузере (IndexedDB) и виден только на этом устройстве:
это способ показать приложение с настоящими фотографиями, а не опубликовать их. Чтобы фото
увидели все гости, положите файл с тем же именем в эту папку и соберите приложение.

Одно исключение: у новинок в панели меняется снимок карточки (`dish-new-0-0`), и он же
подставляется в карусель на главной. Файлом это два разных слота — чтобы заменить снимок
в карусели насовсем, положите сюда ещё и `new-new-0-0.jpg`.

## Откуда снимки сейчас

Все 85 снимков блюд и разделов подобраны через [Openverse](https://openverse.org) —
поиск по каталогам свободных фотографий. Взяты только лицензии CC0, «знак общественного
достояния» и CC BY: их разрешено использовать в коммерческом приложении и обрезать под карточку,
достаточно указать автора. CC BY-SA и лицензии с условиями «некоммерческое» и «без переработки»
не используются.

Автор, лицензия и ссылка на источник каждого снимка лежат в `src/data/photo-credits.json`;
из этого файла собирается документ «Фотографии в приложении» в разделе «Документы»,
а на карточке блюда появляется подпись «Фото иллюстративное».

Подбор повторяем: `scripts/photo-slots.mjs` — список слотов и поисковых запросов,
`scripts/photo-picks.json` — какой из найденных снимков выбран, `scripts/photos.mjs` — сам подбор:

```bash
node scripts/photos.mjs --scan   # собрать кандидатов и превью в .photo-scan
node scripts/photos.mjs          # скачать выбранное сюда
```

## Когда появится собственная съёмка

Своё фото блюда — единственный правильный вариант: гость должен видеть то, что ему подадут.
Положите файл с тем же именем и удалите строку этого слота из `src/data/photo-credits.json` —
подпись «Фото иллюстративное» под карточкой пропадёт сама, а когда файл опустеет,
из списка документов исчезнет и «Фотографии в приложении».

`about-map`, `about-hall` и `about-terrace` намеренно оставлены пустыми: карта и снимки зала
должны показывать именно ваше кафе, чужие сюда ставить нельзя.
